# Kiddom Illustration Library

A simple web app for illustrators to see which illustrations still need to be created (e.g. apple, watermelon) and to add new ones to the library.

## Open locally

This is a static site — no install or build step.

1. Open `index.html` in a browser, or
2. From this folder, run a local server if you have one available, for example:

```bash
python3 -m http.server 5173
```

Then visit `http://localhost:5173`.

## What’s included

- **Icon** view — grid of items to create (square + X placeholders for now)
- **List** view — same items as a list
- **Search** view — filter by name
- **+** button — add a new illustration (name + optional local preview file)
